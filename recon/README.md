# 教务系统侦察脚本

验证一件事：**登录之后，课表 / 空教室 / 电量的数据到底能不能拿到、以什么形式返回。**

数据通不了，安卓 App 写得再漂亮也是空壳。所以先跑这个。

---

## 已经确认的结论（2026-11-06 实测）

| 项目 | 结论 |
|---|---|
| **网络要求** | **不需要校园网**。公网可直接访问，手机流量、家里宽带都行 |
| 系统类型 | **超星综合教学管理系统**（不是正方、不是强智） |
| 登录链路 | `tls.ccsut.cn/admin/caslogin` → 302 → `auth.ccsut.cn/backstage/cas/login` |
| 页面渲染 | **前端渲染 SPA**。HTML 是空壳，数据靠 JS 异步请求 |
| 零信任网关 | `zts.ccsut.cn` 确实存在，但**不影响**教务系统访问 |

最后一条很重要：因为是 SPA，**硬扫 URL 找不到课表接口**——服务端对任何路径都返回同一份空壳，真正的数据在 XHR 请求里。脚本能帮你确认系统类型和登录状态，但接口地址必须靠手动抓一次。

所以：**跑完脚本后，大概率还需要你做一步「抓包」**（见第五节）。

---

## 一、准备

```bash
cd cust-campus-app/recon
pip install -r requirements.txt        # 已装可跳过
```

然后**用记事本打开 `config.json`**，只改 `cookie` 这一项：

```json
{
  "base_url": "https://tls.ccsut.cn/",
  "cookie": "PASTE_YOUR_COOKIE_HERE"   ← 换成真实 Cookie
}
```

**Cookie 获取步骤：**

1. 浏览器登录教务系统，进到**课表页面**（确保登录态是活的）
2. `F12` 打开开发者工具 → 切到 **Network / 网络** 标签
3. 刷新页面 `F5`
4. 点第一条请求（类型是 `document`）
5. 右侧 **Headers** → **Request Headers** → 找到 **Cookie:** 这一行
6. 复制冒号后面**整行内容**

> Cookie 是一长串 `JSESSIONID=xxx; ...` 的形式，复制完整，别漏分号。

## 二、跑

**方式 A：双击 `run.bat`**（最省事，会自动检查依赖，跑完窗口不关）

**方式 B：终端**
```bash
python recon.py
```

**方式 C：让我代跑** —— Cookie 填好后跟我说一声，我在这边直接执行。

如果你已经知道空教室或寝室电量的查询页地址，可以追加探测：

```bash
python recon.py --url "完整网址" --url "另一个完整网址"
```

## 三、看结果

打开 `report.md`，重点看第 1 节：

| 判定 | 含义 | 下一步 |
|---|---|---|
| 认证状态「已登录」 | Cookie 有效，数据链通了一半 | 看第 3/6 节有没有课表链接 |
| 「未登录 / 所有路径都落到登录页」 | Cookie 过期了 | 重新登录复制一次 |
| 「无法判定 —— SPA 兜底路由」 | 前端接管路由，服务端看不出登录态 | 直接走第五节抓包 |
| 页面渲染「前端渲染 SPA」 | 数据在 XHR 里 | 走第五节抓包 |

`dumps/` 目录存了每个页面的完整 HTML，方便对照分析。

## 四、寝室电量要单独给网址

电量查询一般不在教务系统里，通常在后勤平台或一卡通平台。**把那个查询页的完整网址发我**，我加进探测列表。

如果它是个需要输入房间号就能查的公开页面，那最好办——不用登录也能跑。

## 五、关键一步：抓一条 XHR 请求

因为是 SPA，我需要你手动抓一次真实请求。**这是整个项目最关键的一步**，没有它我没法写解析代码。

1. 浏览器登录，进到**课表页面**，等课表显示出来
2. `F12` → **Network / 网络** 标签
3. 点 **Fetch/XHR** 筛选按钮
4. `Ctrl+R` 刷新页面
5. 看列表，逐条点开 **Preview / 预览**，找到返回内容里含**课程名、教室、节次、周次**的那一条
6. 找到后：右键该请求 → **Copy** → **Copy as cURL (bash)**
7. 粘贴到一个 txt 文件里发我

> ⚠️ cURL 里包含你的登录 Cookie，**只发给我本人，不要发群、不要上传网盘**。我解析完会提醒你删掉。

同样方法再抓一条**空教室**查询的请求，一起发我最好。

## 六、安全说明

- Cookie 只存在本地 `config.json`，脚本不向任何第三方发送数据
- `config.json` 已加入 `.gitignore`
- 用完后建议删除 `config.json`
- 脚本对请求间隔 0.35 秒，不会给学校服务器造成压力
